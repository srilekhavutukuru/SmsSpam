
# SMS Spam Detection

## Overview

This project is a simple SMS Spam Detection system developed using Python. The main objective of the project is to classify SMS messages as either Spam or Ham (Not Spam).

In this project, I used basic data analysis and visualization techniques to understand the dataset and classify the messages.

Features
Classifies SMS messages into Spam or Ham
Data analysis using Pandas and NumPy
Data visualization using Matplotlib and Seaborn
Basic classification model implementation
